# Assets TOKKA Contact

Origem: https://github.com/eusettee/tokka-contact, revisão `1cf7f03b94b384d50dd06783b51de5199cb1c917`.

- `tokka-contact.png` e `tokka-waves.png`: arquivos originais de `public/assets/images/`, sem alteração de pixels.
- `fonts/`: fontes Google Sans originais e licença `OFL.txt` preservada. O nome interno do CSS foi isolado como `Tokka Contact Sans` para não afetar o restaurante.
- `icons/`: SVGs de serviços do repositório; Instagram extraído do SVG de `service-icons.js`. Ícones são renderizados somente a partir desses arquivos estáticos.
- `SOURCE-CREDITS.md`: créditos originais completos.

O perfil de demonstração, dados locais, servidor sem autenticação e arquivos de usuários do outro projeto não foram importados. Cada cartão continua usando sua própria conta e seus dados no Firebase.
